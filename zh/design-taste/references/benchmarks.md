# 基准 —— 顶级企业官网到底怎么做

数据来源：2026-10 两次官网抓取（无头 Chromium，1440×900）。一次覆盖全球市值前 100 公司，另一次覆盖市值前 100 的科技/互联网/软件公司。去重后共 147 个站点，用与 `scripts/review_site.py` 相同的公式打分：45% 指标分 + 55% 视觉分。逐站数据见 `scripts/benchmarks.csv`。分数是启发式的，用于站点间比较，而非绝对评级。

## 2. 目标值（前 20 与后 20 站点的中位数，两批合并）

| 指标 | 前 20 | 后 20 | 目标 |
|---|---|---|---|
| 颜色值（文字+背景+边框） | 14 | 29 | ≤ 15 |
| 字体族 | 2 | 2 | ≤ 2 |
| 使用 ≥2 次的字号 | 6.5 | 9 | ≤ 7 |
| 字重 | 2.5 | 3.5 | ≤ 3 |
| 圆角值 | 3 | 6 | ≤ 3 |
| 阴影值 | 0.5 | 3 | ≤ 1 |
| 渐变 | 0 | 1（科技后 20：8） | ≤ 1 |
| Hero 标题 | 61px | 48px | ≥ 56px |
| 正文字号 | 16px | 14px | ≥ 16px（营销页） |
| Hero/正文比 | 3.6 | 3.2 | ≥ 3.5 |
| 正文对比度（加权） | 16.2 | 10.2 | ≥ 12 |
| 低于 AA 的文字 | 0% | ~2–10% | 0% |

字体族数量区分不了好坏。**区分度最高的是颜色数、渐变和阴影：** 最好的站点赢在“用得少”。

## 3. 细分行业打法

每个配方都是起点，映射到 `tokens.md` 的语义命名上。

**医药 / 医疗（最佳品类，均分 76）。** 人文摄影，常为单色；衬线或超宽展示字；暖白。
`--canvas:#FBF8F5; --text:#1A1A1A; --accent:<品牌红/橙/蓝>; 展示字 80–100px 衬线或宽无衬线，正文 18–20px；圆角 0–4px；无阴影；区块在 canvas 与 6% 强调色浅底之间交替。`

**奢侈品 / 时尚零售（LVMH、Inditex）。** 摄影撑起页面，字体保持安静。
`配色 = 黑/白/1 种灰；细或高对比无衬线，导航大写 11–12px、字距 0.1em；圆角 0；阴影 0；CTA = 下划线文字。` 避免徽章和价格贴。大众零售（Walmart、Costco、Amazon）出于商业需要以促销为主，不要拿它们作审美对标。

**金融（均分 66.5，两极分化）。** 赢家（JPMC、Citi、HSBC）像杂志；输家（BofA、中国国有银行、TD）像门户。
`暖白底上用海军蓝或品牌墨色；编辑衬线标题 56–72px + 无衬线正文 16–18px；编号区块（“01”）；导航里一个登录入口，而不是 Hero 里一张登录卡片；利率用 tabular-nums。`

**互联网 / 消费平台（均分约 70）。** 让产品本身就是首页（Airbnb、Spotify、Robinhood），或一张图配一句话（Meta、Booking）。
`一个强调色（标志色）只用于主 CTA；真实 UI 截图；正文 16–18px；胶囊 CTA；对比度 ≥12 时可用深色长页区块。`

**软件 / 云（最差品类，均分 61.6）。** 典型失败是公告条、Gartner 徽章、多色 CTA 和渐变网格。可照抄 IBM。
`一个无衬线字体族（类 Plex）3 种字重；6 个字号（14/16/20/28/40/56）；强调色 = 一种蓝；圆角 0–4px；阴影只用于弹出层；最多 1 条公告条；首屏不放聊天气泡。`

**半导体（视觉分最低，均分 65）。** 多数站点用深色画布 + 蓝/紫光晕 + 芯片渲染，品牌之间难以区分。Intel、KLA、AMAT 给出了替代：一个巨型标题、一个大数字，或真实晶圆厂摄影。
`若用深色：--canvas:#0B0D10，文字 #F2F2F2，强调色 = 品牌色（不是青色光晕），0 渐变；优先真实硬件/晶圆厂照片；标题 ≥72px。`

**硬件 / 设备（均分 66）。** 以摄影为主的产品陈列有效（SpaceX、Apple、Seagate、Nokia）。目录式网格失败（TE、Keyence）。
`每个产品色块用中性底；每个视口一个产品 + 一句话；品类放二级导航，首页绝不放巨型网格。`

**航空航天 / 国防（均分约 80）。** 全幅飞机或发射影像，几乎没有 UI。白色窄体大写、3 种文字颜色、零阴影。

**中国 vs 美国（科技批次）。** 中国站点指标分更好（78 vs 70：颜色更少、几乎没有渐变），但视觉分更差（55 vs 62）。原因是 IR/门户模板、正文对比度低（中位数 8.5）和 12–14px 的中文正文。修法：中文正文 16px、行高 1.7–1.8；在拉丁字体之后使用 `"PingFang SC","Noto Sans SC"`；Hero 只讲一件事而不是新闻轮播；文字对比度 ≥7:1。小米（白底产品陈列 + 一句文案）是最接近 Apple 模式的中国案例。美国站点既有最高分（SpaceX、Robinhood）也有最低分（Palo Alto、Snowflake、Fortinet）。

## 4. 常见错误（附案例）

- **门户化：** 所有频道都堆在首屏，链接墙、图标墙（工商银行、中国银行、中国石油、BofA、Keyence）。修法：一个 Hero，频道移入导航。
- **促销堆叠：** 价格徽章、倒计时、多色标签（Dell、Costco）。B2B 的等价物是公告条 + 奖项徽章 + 活动横幅 + 聊天机器人（ServiceNow、Snowflake、Fortinet）。
- **“AI 科技”模板：** 深色画布、青/紫光晕、粒子、芯片渲染（AMD、Arm、Palo Alto、Synopsys、寒武纪、CrowdStrike）。正是 SKILL.md 中 slop 清单的写照。
- **Token 债：** Palo Alto 用了 20 个字号，Snowflake 42 种颜色和 16 个字号，Shopify 11 种圆角和 10 种阴影，TE Connectivity 9 个字体族，BofA 和 Santander 7 个字体族。
- **照片上的细字：** 灰调图像上压细白字（RTX、AMAT；阿里巴巴 67% 的正文不达 AA；北方华创正文对比度仅 1.7）。
- **遮挡 Hero 的弹层：** cookie 墙、地区选择、纪念弹窗（Delta 泰国、村田、TotalEnergies）。
- **Token 完美但没有层级：** Alphabet IR 和 Berkshire Hathaway 指标分高、视觉分低。光有克制不等于设计。
- **正文过小：** 11–13px 正文（中国银行、高通、Apple 12px 导航密集文字）会扣可访问性分。
