# 极简 / 编辑风格叠加层

当用户要求极简、干净、编辑感、文档感，或“像 Notion/Linear 那样”的沉静时使用。叠加在核心规则之上。

## 气质
暖色单色画布，靠字体对比承担层级，扁平表面，颜色只作为极小的语义点缀。

## 规格（起始值——按需调整）
- **画布：** 白色或暖米白（≈ `#FBFBFA`/`#F7F6F3`）；表面色几乎无差别。
- **文字：** 偏黑（≈ `#111`–`#2F3437`），次级文字低饱和（≈ `#787774`）；正文行高约 1.6。
- **边框：** 发丝线，非常浅（≈ `#EAEAEA` 或 `rgb(0 0 0 / .06)`）。用边框代替阴影。
- **点缀色：** 去饱和的马卡龙色，只用于标签/徽章，每个都配同色相的深色文字。
- **字体：** UI 用中性无衬线 + 大标题/引文用编辑衬线（字距紧、行高约 1.1）+ 元数据/快捷键用等宽。
- **圆角：** 利落——按钮 4–6px，卡片 ≤ 8–12px，标签用胶囊。
- **阴影：** 无或几乎不可见。**渐变：** 无。
- **按钮：** 实心深色主按钮、浅色文字、无阴影；悬停 = 轻微色调变化。
- **布局：** 宽裕内边距、带扁平描边单元格的不对称 Bento 网格、用分隔线分行的手风琴、`<kbd>` 风格的快捷键标签。
- **动效：** 极少，短促的透明度/位移淡入淡出。

## 避免
重阴影、毛玻璃、渐变、高饱和品牌色铺满、emoji、过大圆角、无目的的装饰插画。
