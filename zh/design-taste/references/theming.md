# 幻灯片、文档、报告的主题

主题 = **配色（4–6 种有角色的颜色）+ 字体搭配（标题/正文）+ 几条布局规则。** 在每一页/每一张幻灯片上一致地应用。

## 流程
1. 识别产物与场景（融资路演、内部报告、教学文档、HTML 讲义）。
2. 提供 3–6 个命名主题选项（名称 + 一句话氛围 + 色板 + 字体），或从给定品牌推导。可行时让用户选；否则自行选择并说明理由。
3. 应用：一次性设置主题变量（母版、文档样式、CSS 变量），绝不逐元素写字面量。
4. 检查每种背景上文字的对比度；检查图表按固定顺序使用配色。

## 主题配方
| 角色 | 示例 |
|---|---|
| 背景 | 暖米白 / 深海军蓝 |
| 表面 | 与背景略有偏移 |
| 主 / 次文字 | 偏黑 / 低饱和 |
| 强调色 1（主强调） | 一个饱和色相 |
| 强调色 2（数据/次要） | 互补或邻近色相 |
| 字体 | 有个性的标题字 + 高可读的正文字 |

氛围起点（自行命名和取值）：*深海*（海军蓝、青绿、沙色）、*森林*（深绿、苔绿、奶油）、*日落*（珊瑚、梅紫、蜜桃）、*现代极简*（石墨、白、一个信号色）、*午夜科技*（近黑、电光青）、*沙漠玫瑰*（灰粉、赤陶、陶土）。

## 幻灯片要点
- 一页一个观点；标题直接写结论。
- 大字号（标题 36–54pt，正文 ≥ 18pt），最多约 6 行。
- 网格与页边距一致；出血图片要有意为之。
- 图表：去掉图表垃圾，直接标注，用强调色突出唯一重要的那条序列。

## 文档/报告要点
- 清晰的标题层级（≤ 3 级），行长 60–75ch（中文约 30–40 字），表格样式一致，图片带图注。
