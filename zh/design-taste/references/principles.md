# 视觉原则

## 色彩
- 60/30/10：主体中性表面、次级表面/文字、约 10% 强调色。
- 强调色只标记*可交互或重要*的东西。处处强调等于没有强调。
- 长文阅读不要用纯 `#000` 文字配纯 `#fff` 背景；用偏黑/偏白。
- 彩色背景上的灰字：改用背景色相的深浅变体。
- 渐变：细微且有目的（光照、纵深），不要拿来当品牌。
- ❌ 紫/靛→蓝的 Hero 渐变、霓虹发光、彩虹图表。✅ 一块自信的色域、带色调的中性色。

## 字体排印
- 模数比例（如 1.2–1.333）：12 / 14 / 16 / 20 / 24 / 32 / 48 / 64。字号 ≤ 6–8 档。
- 字重 2–3 种（如 400 / 500 / 700）。层级 = 字号 + 字重 + 颜色，而不是到处全大写。
- 行长上限约 65ch；网页避免两端对齐；标题避免孤字（`text-wrap: balance`）。
- ❌ 全部 14px 中灰。✅ H1 → 正文 → 说明文字层级分明。

## 间距与布局
- 4/8px 基准尺度：4、8、12、16、24、32、48、64、96、128。
- 亲密性：内边距 < 组间距 < 区块间距。
- 使用网格（12 栏或基于内容）；对齐边缘。有意为之的不对称没问题。
- 打破“Hero + 3 张卡片”模板：试试分栏布局、大字、列表、表格、跨度各异的 Bento、元素重叠。
- 不要把所有东西都装进卡片。用留白、分隔线或背景色变化来分组。
- 响应式：分别认真设计移动端和桌面端；不要只是缩小。

## 圆角
- 一个圆角族：如 4（输入框、标签）/ 8（卡片）/ 9999（胶囊）。嵌套圆角 = 外圆角 − 内边距。
- 小圆角显得技术/编辑感；大圆角显得柔和/消费感。按风格选，不要随意混用。

## 阴影与层次
- ≤ 3 个高度层级（浮起、浮层、模态）。阴影柔和、低不透明度、多层叠加；向背景色相偏色。
- 扁平/极简风格优先用边框或表面色调变化。同一张卡片不要同时有阴影 + 边框 + 渐变。
- 深色模式：用更亮的表面表现高度，而不是阴影。

## 动效
- 目的：反馈、连续性、方向感。不是装饰。
- 时长：100–150ms（微交互：悬停/按下）、200–300ms（进入/退出）、≤ 500ms（页面级）。
- 进入用 ease-out，退出用 ease-in；UI 避免 linear；除非是活泼风格，避免弹性/回弹。
- 只动画 `transform` 和 `opacity`；UI 过渡永远不要动画 width/height/top/left。
- 一个精心编排的时刻（如错峰的页面加载）胜过零散的特效。
- 始终尊重 `prefers-reduced-motion`。

## 图标与图像
- 一套图标、一种描边粗细，尺寸与旁边文字匹配。不要用 emoji 当 UI 图标。
- 使用真实或专门制作的图像；裁切、比例、处理方式保持一致。

## 文案
- 用具体的动词和名词。禁用：“赋能”“无缝”“释放潜能”“下一代”“颠覆”（以及英文的 Elevate、Seamless、Unleash、Next-gen、Revolutionize）。
- 按钮写清会发生什么（“创建发票”，而不是“提交”）。
- 错误信息：发生了什么 + 怎么解决。
