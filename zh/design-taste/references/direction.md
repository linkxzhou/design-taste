# 设计方向

## 目录
1. 需求提问  2. 风格目录  3. 选字体  4. 选配色  5. 写下方向

## 1. 需求提问
- 这个界面唯一的主操作是什么？
- 谁在用、多久用一次、用什么设备？（日常工具 → 密度与速度；一次性访问 → 第一印象与清晰）
- 品牌必须让人*真实*感受到什么（可信、快、精工、有趣）？
- 已有哪些资产（logo、颜色、字体、组件库）？先复用，再发明。

## 2. 风格目录（选一个，然后坚持）
| 风格 | 感觉像 | 典型手法 |
|---|---|---|
| 编辑 / Editorial | 杂志、长文 | 衬线展示字 + 安静的无衬线、宽页边、明确分隔线、少量颜色 |
| 瑞士 / 功能主义 | 导视、规格书 | Grotesk 字体、严格网格、左对齐、一个信号色 |
| 技术 / 高密度 | 终端、交易 | 等宽点缀、紧凑行、等宽数字、深色或中性 UI |
| 柔和 / 有机 | 健康、消费 | 圆润造型、暖中性色、温和动效 |
| 奢华 / 安静 | 时尚、酒店 | 高对比衬线、大量留白、近乎单色 |
| 粗野主义 / 原始 | 艺术、独立 | 系统字体、硬边框、外露结构、高调色块 |
| 活泼 | 儿童、游戏、创作者工具 | 粗壮字体、高饱和配色、弹性动效（克制使用） |
| 复古 / 工业 | 硬件、档案 | 窄体字、低饱和油墨色、质感、标签 |

两种风格混搭可以，但必须有一个明确主导。

## 3. 选字体
- 靠**对比**搭配，而不是相似：衬线展示字 + 中性无衬线；Grotesk + 等宽；窄体 + 人文无衬线。
- 正文：高可读，网页 16px 以上，行高 1.5–1.7，每行 60–75 个字符（中文约 30–40 字）。
- 标题：行高更紧（1.05–1.25），大字号时字距略收。
- 避免条件反射式默认（到处 Inter、Roboto、Arial、Space Grotesk）。有意图地选择；对粗野主义/工具风格来说，系统字体栈也是合理的*有意*选择。
- 数据用等宽数字（tabular numerals）。

## 4. 选配色
- 从中性色出发（偏暖或偏冷，而非纯灰），再加**一个**强调色；第二个强调色必须有明确职责。
- 语义色（成功/警告/危险/信息）与品牌强调色分开定义。
- 深色模式是一套独立配色，不是反色：降低饱和度，用更亮的表面色而不是阴影来表现层级。
- 对实际用到的每一组文字/背景检查对比度。

## 5. 写下方向（模板）
```
方向：面向 <受众> 的 <风格>，为 <主操作> 优化。
字体：<展示字> / <正文字>（+ <等宽>）。配色：<中性色族> + <强调色>（+ 语义色）。
记忆点：<一个让人记住的手法>。密度：<疏朗|均衡|密集>。动效：<无|细微|表现性>。
```
